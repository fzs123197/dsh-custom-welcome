# dsh-custom-welcome

替换 DSH 新会话首页欢迎标题与副标题的客户端插件。

## 效果

| 位置 | 原文 | 替换后 |
| --- | --- | --- |
| 主标题 `<h1>` | 探索未至之境 | 欢迎使用DSH |
| 副标题 `<h1 + p>` | Into the Unknown | Custom AI Harness |

## 文件结构

- `plugin.json` — 插件清单，声明插件名称、版本与客户端入口
- `client.js` — 客户端脚本，负责检测并替换首页欢迎文字

## 安装

将本仓库克隆到本地，然后执行（`<本目录绝对路径>` 替换为实际路径）：

```bash
dsh plugin --profile web add link:"<本目录绝对路径>"
```

重启 web 服务后，新建会话即可看到替换效果。

## 自定义文字

直接修改 `client.js` 中双引号内的文本即可：

- `欢迎使用DSH` → 你想要的主标题
- `Custom AI Harness` → 你想要的副标题

## 实现说明

- 仅在首页执行：以「欢迎主标题仍为原始文案」作为首页特征，检测到才启动替换轮询，离开首页自动停止，减少无谓轮询。
- 通过 `MutationObserver` 监听 DOM 变化，兼容 SPA 路由切换。
- 若页面结构调整导致选择器失效，需同步调整 `client.js` 中的 `h1` / `h1 + p` 选择器。
