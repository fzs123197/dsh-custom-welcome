# dsh-custom-welcome

DSH（DeepSeek Harness）客户端插件：替换新会话首页欢迎文字与鲸鱼图标，并在 **设置** 中提供自定义页面。

## 功能

- **首页欢迎文字替换**：将新会话首页主标题「探索未至之境」/「Into the Unknown」替换为设置中的文案（预览版徽章保留不动）。
- **首页图标替换**：将欢迎页鲸鱼图标替换为自定义 Emoji（如 🚀）或图片链接；留空则保留默认鲸鱼，填 `none` 则不显示（连默认鲸鱼一起隐藏）。
- **左上角品牌图标替换**：将侧边栏左上角鲸鱼 logo 替换为自定义 Emoji 或图片；留空则保留默认鲸鱼，填 `none` 则不显示。
- **左上角品牌名称替换**：将侧边栏左上角品牌文字「DeepSeek Harness」替换为自定义 Emoji 或文字；留空保留官方字标，填 `none` 则不显示。
- **窗口标题**：在设置中填写「窗口标题」后，桌面窗口标题（任务栏显示的名称）即替换为自定义文字；留空保持应用默认。SPA 若自行重设标题会自动恢复为你的设置。
- **设置页**：打开 DSH 设置 → **自定义欢迎文字**，编辑「首页主标题」「首页副标题」「首页图标」「左上角图标」「左上角品牌名称」「窗口标题」，保存后立即生效（无需重启）。
- **首页替换全程生效**：以 `titleGroup` 结构定位首页标题（非依赖原始文案文本），启动早期设置值尚未就绪时先应用默认值、设置值到达后自动更新为自定义内容，SPA 路由切换回首页时自动重新应用。
- **图标不可选中**：自定义图标（欢迎页 / 左上角）不可被鼠标选中或拖拽。
- 设置值持久化到 Host 设置文档（与官方设置页同一机制），支持「恢复默认」。
- **保存不被陈旧修订拒绝**：插件重装/热重载/多窗口会让设置服务修订号与本地快照不一致，官方表单默认按修订号做冲突保护，会把正常保存误判为陈旧写入而拒绝（显示“本部署没有接受这些值”）；本插件保存时直接以「无修订号约束」写入（服务端跳过冲突检查），保存必定被接受，成功后与设置文档同步。

## 安装

```bash
dsh plugin --profile web add link:"<本仓库绝对路径>"
```

桌面端在 **插件** 面板中从 GitHub 仓库添加（`https://github.com/fzs123197/dsh-custom-welcome`）。
插件安装后暂不支持自动更新：升级需先卸载再安装新版。

## 使用

1. 打开 DSH Web，进入 **设置 → 自定义欢迎文字**。
2. 修改「首页主标题」「首页副标题」「首页图标」，点击 **保存**（留空保存 = 恢复默认）。
3. 回到新会话首页即可看到新文字与新图标。
4. （可选）填写「左上角品牌名称」替换侧边栏顶部「DeepSeek Harness」文字，填 `none` 隐藏。
5. （可选）填写「窗口标题」后，桌面窗口任务栏名称即替换为自定义文字；仅桌面端窗口生效，Web 端不生效。

「首页图标」与「左上角图标」支持三种形式：
- **Emoji / 文字**：直接填写，如 `🚀`、`DSH`。
- **图片链接**：填写 `http(s)://`、`data:image` 或 `/` 开头的图片地址，按原始比例渲染。
- **本地图片**：点击「选择本地图片」按钮，从本机选择图片文件，自动转为 data URL 写入并保存；**超过 128KB 的 PNG/JPG/WebP/SVG 会自动压缩**（最长边 512px、WebP 质量 0.85）后再保存，避免大 data URL 导致设置保存被拒绝。
- **不显示**：点击「不显示」按钮（或直接填写 `none`），该图标连默认鲸鱼一起隐藏；留空即恢复默认。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `package.json` | npm 包清单 + `dsh` 插件声明（`dsh.bundle.patch`、`dsh.client`） |
| `cordis.patch.yml` | bundle patch：插入 `custom-welcome` 插件行 |
| `lib/index.js` | 宿主半侧：声明设置命名空间 `custom-welcome` 的 volatile 字段 |
| `lib/client.js` | 浏览器半侧：设置分区注册 + 首页文字/图标替换 |

## 说明

- 插件包名：`dsh-custom-welcome`；设置命名空间（条目 id）：`custom-welcome`。
- 默认文案：主标题 `欢迎使用DSH`、副标题 `Custom AI Harness`（见 `lib/index.js` 的 Config 默认值）；图标默认留空（保留官方鲸鱼）；窗口标题默认留空（保持应用默认）。
- **窗口图标限制**：任务栏/窗口图标来自 DSH 应用自身的安装资源，桌面主进程未提供运行时替换图标的接口（`DESKTOP_IPC` 无相关通道，preload 也未暴露），插件层无法修改窗口图标；如需更换需改动应用本体资源，超出本插件能力。
- 首页标题元素为 `span.titleGroup` 内的裸文本 `span`（非 h1）；「预览版」徽章是独立元素，替换时保留。
- 欢迎页图标通过官方插槽 `conversation.hero.brand.mark` 注册；左上角图标通过 `sidebar.brand.mark` 插槽、左上角品牌名称通过 `sidebar.brand.name` 插槽注册（均负优先级覆盖官方鲸鱼/官方字标），替换仅在设置了值时生效（留空即注销，回退官方；`none` 渲染空）。
- 「副标题」字段是兼容保留项：当前 DSH 欢迎页没有独立副标题（`Into the Unknown` 实为英文 locale 的主标题），无匹配元素时不生效。
- 若页面结构变化导致定位失效，需同步调整 `lib/client.js` 中的 `findHeadline()`。
